## ⚡ Overview

This repository contains the source code for **Giridharan K's** interactive Cyber HUD portfolio website. Designed with a high-tech terminal aesthetic, glassmorphic HUD overlays, matrix particle canvas rendering, tactile audio feedback, and an instant search/filter engine for verified credentials.

---

## 🔥 Key Features

- **🚀 Ultra-Fast WebP Asset Engine**: Hero feeds and visual assets are optimized WebP format for sub-second load times.
- **📜 Global Certifications Registry**: Clean, high-performance display of verified digital credentials and specialization certificates.
- **🎯 TryHackMe Achievement Dashboard**: Integrates official TryHackMe badge and interactive room counters with scroll-triggered animation.
- **🔊 Tactile Audio SFX Engine**: Synthesizes futuristic UI interaction sounds on button clicks, toggles, and filters using the browser's native Web Audio API.
- **🌓 Dynamic Dark / Light Theme**: Seamless theme toggling powered by modern CSS custom properties and frosted glassmorphism overlays.
- **⚡ Layout & Performance Optimized**: Built with `loading="lazy"`, `decoding="async"`, `<link rel="preload">` resource hints, and strict layout dimension bounds to prevent Cumulative Layout Shift (CLS).

## 🚀 Quick Start / Local Deployment

No heavy build step or Node environment required! To run locally:

1. Clone or download the workspace:
   ```bash
   git clone https://github.com/nextboxis/protflio.git
   cd protflio
   ```
2. Launch with any HTTP server (or open `index.html` directly in your browser):
   ```bash
   # Using Python 3
   python -m http.server 8000
   ```
3. Open `http://localhost:8000` in your web browser.
